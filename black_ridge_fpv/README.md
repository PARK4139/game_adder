# BLACK RIDGE FPV (가칭)

BETAFPV Meteor 75 한 대로 광활한 검은 절벽·검은 바위·설산을 탐험하는 사실적인 FPV 비행 게임.

## 현재 상태

2026-10-15 기준: 실행 기반 `367c7496`과 키보드 입력 `a78b16c0` 진행 중. UE 5.8용 프로젝트 뼈대와 Enhanced Input 코드·스무딩·진단 화면 소스를 준비했다. 마지막 화면에서 UE 5.8.3 설치 중이었으며 컴파일·에디터·입력 동작은 아직 검증하지 않았다. 플레이 가능한 비행 기능은 아직 없다.

## 프로젝트 경계

이 폴더는 FPV 게임 전용이다. 자동차 추격 영상 프로젝트는 형제 폴더 `../car_chase_previs/`에서 관리한다.

- 게임 기획, 구현, 에셋, 검증 기록은 이 폴더 아래에 둔다.
- 자동차 프로젝트의 파일이나 자산 경로를 직접 참조하지 않는다. 자산을 재사용할 때는 라이선스와 출처를 확인하고 의존성을 별도로 기록한다.
- 현재는 같은 Git 저장소 안에서 폴더를 분리한 상태다.
- 엔진 선정 후 게임 소스와 엔진별 생성 파일 제외 규칙을 추가한다.

## 기획 출처

이 프로젝트 작업 경로에서 진행한 이전 대화 `01a13448-e097-7672-b1f3-f8d351932c3e`의 Meteor 75 게임 요청 및 키보드 우선 제어 합의를 옮겼다. 기존 자동차 작업 문서에는 이 게임 기획이 포함되어 있지 않아, 이동할 게임 구현 파일은 없었다.
