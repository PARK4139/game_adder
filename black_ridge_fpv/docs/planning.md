# FPV 게임 기획

정리일: 2026-10-15

## 사용자가 정한 방향

- Photorealistic / Hyperrealistic 비주얼.
- 광활한 검은 절벽, 검은 바위, 설산 지대.
- BETAFPV Meteor 75 한 대를 조종하며 비행하고 주변 경관을 살펴본다.
- 키보드 제어를 먼저 구현한다. 게임패드·실제 FPV 조종기 연결은 이후 진행한다.
- 자동차 추격 프로젝트와 별도 폴더에서 관리한다.

## 이전 대화에서 제안한 구성

아래 항목은 제작 제안이며 확정 사양이 아니다.

- 가칭: BLACK RIDGE FPV.
- 엔진: Unreal Engine 5. Nanite, Lumen, World Partition 활용 검토.
- 첫 데모: 약 2×2km의 협곡·능선·착륙 지점에서 3~5분 자유 비행.
- 먼저 단순한 테스트 지형에서 조종과 충돌을 검증한 뒤 절벽·설산의 시각 품질을 개선한다.
- 입력과 비행 물리를 분리하고 스로틀·피치·롤·요 네 축으로 입력을 전달한다.
- 키보드 입력은 부드럽게 증감하며 초기에는 수평 복귀 보조를 제공한다. Acro 모드는 이후 검토한다.
- FPV 시점과 외부 관찰 시점, 재시작, 배터리·체크포인트, 바람·소리는 단계적으로 검토한다.

### 초기 키 배치 제안

| 키 | 기능 |
|---|---|
| W / S | 전후 기울이기 |
| A / D | 좌우 기울이기 |
| ← / → | 좌우 회전 |
| ↑ / ↓ | 스로틀 증가·감소 |
| Space | 수평 복귀·감속·고도 유지 보조 |
| R | 안전한 위치에서 다시 시작 |
| Tab | FPV / 외부 관찰 시점 전환 |
| Esc | 일시정지·설정 |

## 미결정 사항

- 게임 엔진과 버전, 설치 상태.
- 기준 Meteor 75 모델·연식과 비행 물리의 재현 수준.
- 키 배치와 보조 기능의 세부 동작.
- 실제 맵 규모, 성능·화질 목표, 사용할 에셋과 라이선스.
- 자유 탐험 외 미션·승패·성장 시스템의 필요 여부.

## 다음 구현 목표

작은 테스트 공간에서 키보드만으로 이륙 → 전진 → 회전 → 주변 탐험 → 착륙·재시작이 가능하도록 만든다. 현재 이 흐름을 실행할 게임 프로젝트나 빌드는 없다.
