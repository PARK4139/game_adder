# 키보드 우선 FPV 게임 실행 계획

작성일: 2026-10-15. 첫 이슈에서 UE 5.8 실행 기반을 준비 중이며 게임플레이 구현은 미착수다.

## 목표와 범위

Meteor 75 한 대로 검은 절벽과 설산을 탐험하는 PC 데모를 만든다. 작은 테스트 공간에서 키보드 비행을 완성한 뒤 탐험 지형과 사실적인 비주얼을 적용한다. 자동차 프로젝트와 파일·런타임 의존성을 분리한다.

게임패드·USB 조종기, Acro 모드, 배터리 시뮬레이션, 미션·성장 시스템, 멀티플레이는 후속 검토 대상이다.

## 기술 결정

공식 최신 정식 메이저 버전을 확인해 UE 5.8을 선택했다. 설치 시 제공되는 최신 정식 핫픽스와 정확한 빌드 번호를 기록한다. 설치 상태와 실행 절차는 [engine_baseline.md](engine_baseline.md)를 따른다. 지형·조명 기술은 작은 장면에서 측정한 뒤 선택한다. 현재 엔진 설치·실행 검증은 완료하지 않았다.

Meteor 75의 연식·모델과 실제 사양은 구현 전 공식 자료로 확인한다. 게임 내 비행 파라미터와 실제 기체 사양을 구분하고, 설산 탐험 설정을 실제 기체의 운용 성능으로 설명하지 않는다.

약 2×2km는 이전 제안이다. 테스트 공간에서 시작해 3분 대표 경로와 메모리·로딩 측정을 기준으로 실제 맵 크기를 기록한다. 입력은 스로틀·피치·롤·요 네 축으로 물리와 분리한다. 키 배치는 planning.md의 제안을 검증하며 조정 기록을 남긴다.

## 검증과 일정 운영

실행 순서는 [priority.md](../issues/priority.md), 수용 기준은 [requirements.md](requirements.md)가 기준이다. 엔진 확인 전에는 기간을 확정하지 않는다. A 완료 후 B의 실제 작업량을 측정해 이후 단계 예상 기간을 갱신한다.

초기 성능 예산은 1080p 평균 60 FPS, 1% low 45 FPS 이상, 전용 VRAM 최대 7 GiB다. 대상 PC는 보고된 RTX 4070 Laptop GPU 8GB이며 첫 단계에서 확인한다. 미달은 측정값·병목·수정 결과와 함께 기록하며 조용히 목표를 낮춰 완료하지 않는다.

착수할 때만 UUID 파일을 backlog에서 working으로 옮기고 실제 세션을 연결한다. 실행 증거는 canonical path constant로 해석한 `{D_TEMP}/evidence/black_ridge_fpv/verification/{uuid}/`, 결과 요약은 `{D_TEMP}/evidence/black_ridge_fpv/verification/E_{uuid}.md`에 기록한다. 프로젝트 안에 literal D_TEMP 폴더를 만들지 않는다.

AC와 증거가 모두 통과한 이슈만 closed로 이동하고 Active 행을 제거한다. 전체 완료에는 AC-012의 빌드 재현과 키보드 탐험 흐름 검증이 필요하다. 이번 작업은 계획 수립과 이슈 등록이며 게임 구현 완료가 아니다.
